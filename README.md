# Saborella — Cardápio digital

Protótipo responsivo e PWA. Abra `index.html` ou sirva o diretório por HTTPS para testar instalação. Produtos e preços são demonstrativos. Antes de publicar para clientes, substituir as amostras, adicionar a logomarca aprovada, inserir o WhatsApp oficial, regras de entrega e implementar painel com autenticação e persistência compartilhada.
